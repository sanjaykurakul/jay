super() Keyword
to call the parent class's no-argument constructor.
super() Must Be First..
This is wrong:
Student() {

    System.out.println("Student");

    super();   // ❌
}
super() must be the first statement in the constructor.
Correct:
Student(){
    super();
    System.out.println("Student");
}

Parent Constructor with Parameters:
Now suppose the parent doesn't have a no-argument constructor.
class Person {

    String name;

    Person(String name) {

        this.name = name;
    }
}
class Student extends Person {

    int marks;

    Student(String name, int marks) {

        super(name);

        this.marks = marks;
    }
}
COMPLETE EXAMPLE:
import java.util.*;

class Person {

    String name;
    int age;

    Person(String name, int age) {

        this.name = name;
        this.age = age;

        System.out.println("Person constructor");
    }

    void displayPerson() {

        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}

class Student extends Person {

    int marks;

    Student(String name, int age, int marks) {

        super(name, age);            //means:Call the constructor of the parent class with name and age.

        this.marks = marks;

        System.out.println("Student constructor");
    }

    void displayStudent() {

        System.out.println("Marks: " + marks);
    }
}

public class InheritanceConstructor {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        String name = sc.nextLine();
        int age = sc.nextInt();
        int marks = sc.nextInt();

        Student s = new Student(name, age, marks);

        s.displayPerson();
        s.displayStudent();
    }
}
